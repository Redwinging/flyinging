# Flyinging 复算器

面向手机的轻量级实数与复数计算器，以 PWA 形式通过 GitHub Pages 发布。无需应用商店，不需要后端，计算过程不会上传数据。该程序使用AI实现。

## 在线使用

网页地址：https://redwinging.github.io/flyinging/

打开网页即可使用。首次加载完成后，应用会缓存到手机本地，之后即使断网也能继续打开和计算。

## 手机安装

### Android

1. 使用 Chrome 或 Microsoft Edge 打开上方网页地址。
2. 等待页面完全加载。
3. 点击右上角设置按钮，选择“下载”。
4. 确认安装后，可从手机桌面直接打开。

Chrome 没有显示安装提示时，打开浏览器菜单，选择“安装应用”或“添加到主屏幕”。

Microsoft Edge 的方法：打开右上角浏览器菜单，选择“安装此站点为应用”或“添加到手机”，确认后即可从桌面打开。Edge 的菜单名称可能随版本略有不同。

### iPhone

1. 使用 Safari 打开上方网页地址。
2. 点击浏览器底部的分享按钮。
3. 向下找到并选择“添加到主屏幕”。
4. 确认名称为“复算器”，点击“添加”。

iPhone 需要从 Safari 添加，Chrome 或其他浏览器可能不会显示“添加到主屏幕”选项。

## 功能

- 单一计算界面，同时处理实数与复数表达式。
- 主键盘共 9 行：第一行是 `C`、左右括号与退格，第二行 `sin` `cos` `tan` `INV`，第三行幂、平方根、平方与常数 `e`，其后是常数、复数按键与数字键盘。
- 加减乘除、括号、小数和百分比。
- 三角函数 `sin`、`cos`、`tan` 直接在主键盘上，按当前角度单位计算（角度制下 `sin(30)` 为 `0.5`）。
- `INV` 键在正运算与反运算之间切换，切换到反运算后三个三角函数键变为 `sin⁻¹`、`cos⁻¹`、`tan⁻¹`（即 `asin`、`acos`、`atan`），结果同样使用当前角度单位。
- 幂与根：`xʸ` 输入 `^`（右结合，`2^3^2` 为 `512`），`x²` 直接平方，`√` 为平方根（复数也适用，`√(−4)` 为 `2i`）；任意次根用幂写成 `x^(1/n)`，例如 `27^(1/3)` 为 `3`。
- 自然常数 `e` 用 `e` 键输入，可参与指数与幂运算，例如 `e^2`。
- 虚数单位 `i` 与共轭运算。
- 使用 `r∠θ` 输入极坐标，按键在角度制与弧度制之间切换，左侧高亮显示当前单位；角度为算式时使用括号，例如 `5∠(π/2)`。
- 结果下方的极坐标行可点击，在角度制与弧度制之间单独切换，并显示当前单位徽标；该行默认始终为角度制，不随按键单位变化。
- 支持圆周率 `π`，可用于普通表达式和极坐标角度，例如 `5∠π`。
- `‖` 为并联计算，`a‖b` 等于 `a×b÷(a+b)`，支持链式写法如 `6‖3‖2`，也可用于复数与极坐标，例如 `5∠90‖5∠90`。
- 输入有效算式时实时预览结果，算式不完整时不显示占位符；未闭合的括号在预览和按 `=` 时都会自动补齐，例如输入 `sin(30` 直接得到 `0.5`，按 `=` 后算式补成 `sin(30)`。
- 算式输入支持可见光标，可点击或用方向键移动位置后继续修改。
- 输入运算符后仍会预览删除该运算符前的可计算结果，例如输入 `9×` 时显示 `9`。
- 负号不能连续使用；需要负数时使用括号，例如 `9−(−5)`。
- 按 `=` 时若算式结果为无穷或 NaN（例如 `tan(90)` 在角度制下），结果显示“算式错误：结果无定义”；除数为零显示“算式错误：除数不能为零”。
- 输入 `∠` 后只能继续输入角度数字、`π` 或括号角度表达式，其他运算符和 `i` 会被阻止。
- 极坐标角度会在算式中显示为独立分组，连续极坐标相乘时不会与后续运算符混淆。
- 并联符号 `‖` 只合并紧贴它的两个量（数字、复数、`π`、括号表达式或 `conj(...)`），因此优先级高于加减乘除；需要其他结合顺序时请加括号。
- 右上角设置抽屉提供“下载”和“清除离线数据”操作。
- 设置抽屉顶部的“显示大小调整”默认折叠，展开后可分别调节算式字号和结果字号，默认值为 34px，范围为 8 至 64px，设置会保存在本机。
- 主界面会根据可用屏幕高度自动压缩按键区域，首次打开和刷新后使用相同的布局规则。
- 设置抽屉以平移动画进入，遮罩不会额外播放淡入动画。
- 清除离线数据会注销当前应用的 Service Worker、删除应用缓存、角度单位和显示大小设置，并提示手动移除主屏幕图标。
- 复数结果同时显示直角坐标和极坐标。
- 可添加到手机主屏幕，并在断网后继续使用。
- 新版本发布后由用户确认更新。

```powershell
pnpm install
pnpm dev
```

```powershell
pnpm check
pnpm test:e2e
pnpm build
pnpm icons:generate
```

## 发布与更新

1. 在 GitHub 仓库的 `Settings > Pages` 中，将发布来源设为 `GitHub Actions`。
2. 推送到 `main` 分支后，工作流会自动检查、构建并发布。
3. 正式地址为 `https://redwinging.github.io/flyinging/`。
4. 已安装的 PWA 在联网后再次打开时会检查新版本，并显示更新确认。

## 计算引擎

表达式解析由 mathjs 负责。应用按需加载四则运算、复数、共轭、虚数单位、圆周率、三角函数（含反三角）、幂与平方根等模块。求值前会先做两步文本展开：`r∠θ` 按当前角度单位转换成直角坐标字面量 `(a+bi)`，`a‖b` 展开为 `((a)*(b))/((a)+(b))`，再交给 mathjs。三角函数不给 mathjs 传纯角度，而是注入一层按当前角度单位换算的包装函数（`sin(x)` 等价于 `sin(x·π/180)`，反三角反过来），这样 `sin(30)` 与 `asin(0.5)` 都直接使用角度制；`tan` 撞到奇点（角度制 90° 及附近）时按“结果无定义”处理，而不是显示 1.6e16 这类浮点噪声。后续增加对数、指数或复变函数时，在计算核心中显式加入对应依赖和按键即可。
