# Flyinging 复算器

面向手机的轻量级实数与复数计算器，以 PWA 形式通过 GitHub Pages 发布。无需应用商店，不需要后端，计算过程不会上传数据。该程序使用codex实现。

## 在线使用

网页地址：https://redwinging.github.io/flyinging/

打开网页即可使用。首次加载完成后，应用会缓存到手机本地，之后即使断网也能继续打开和计算。

## 手机安装

### Android

1. 使用 Chrome 打开上方网页地址。
2. 等待页面完全加载。
3. 点击右上角设置按钮，选择“下载”；也可以使用 Chrome 菜单中的“安装应用”或“添加到主屏幕”。
4. 确认安装后，可从手机桌面直接打开。

### iPhone

1. 使用 Safari 打开上方网页地址。
2. 点击浏览器底部的分享按钮。
3. 向下找到并选择“添加到主屏幕”。
4. 确认名称为“复算器”，点击“添加”。

iPhone 需要从 Safari 添加，Chrome 或其他浏览器可能不会显示“添加到主屏幕”选项。

## 功能

- 单一计算界面，同时处理实数与复数表达式。
- 加减乘除、括号、小数和百分比。
- 虚数单位 `i` 与共轭运算。
- 使用 `r∠θ` 输入极坐标，可在角度制与弧度制之间切换；角度为算式时使用括号，例如 `5∠(π/2)`。
- 支持圆周率 `π`，可用于普通表达式和极坐标角度，例如 `5∠π`。
- 输入有效算式时实时预览结果，算式不完整时不显示占位符。
- 算式输入支持可见光标，可点击或用方向键移动位置后继续修改。
- 输入运算符后仍会预览删除该运算符前的可计算结果，例如输入 `9×` 时显示 `9`。
- 负号不能连续使用；需要负数时使用括号，例如 `9−(−5)`。
- 输入 `∠` 后只能继续输入角度数字、`π` 或括号角度表达式，其他运算符和 `i` 会被阻止。
- 极坐标角度会在算式中显示为独立分组，连续极坐标相乘时不会与后续运算符混淆。
- 右上角设置抽屉提供“下载”和“清除离线数据”操作。
- 设置抽屉顶部可分别调节算式字号、结果字号和按键大小，设置会保存在本机。
- 主界面会根据可用屏幕高度自动压缩按键区域，较低屏幕会使用更紧凑的默认字号。
- 设置抽屉以平移动画进入，遮罩不会额外播放淡入动画。
- 清除离线数据会注销当前应用的 Service Worker、删除应用缓存、角度单位和显示大小设置，并提示手动移除主屏幕图标。
- 复数结果同时显示直角坐标和极坐标。
- 可添加到手机主屏幕，并在断网后继续使用。
- 新版本发布后由用户确认更新。

## 本地开发

```powershell
pnpm install
pnpm dev
```

本地地址为 `http://localhost:5173/flyinging/`。

常用检查：

```powershell
pnpm check
pnpm test:e2e
pnpm build
pnpm icons:generate
```

## 发布与更新

1. 在 GitHub 仓库的 `Settings > Pages` 中，将发布来源设为 `GitHub Actions`。
2. 推送到 `main` 分支后，工作流会自动检查、构建并发布。
3. 正式地址为 `https://redwinging.github.io/flyinging/`。
4. 已安装的 PWA 在联网后再次打开时会检查新版本，并显示更新确认。

## 计算引擎

表达式解析由 mathjs 负责。应用仅加载当前需要的四则运算、复数、共轭、虚数单位和圆周率模块。`r∠θ` 会根据当前角度单位在求值前转换为直角坐标表达式。后续增加乘方、开方、指数或对数时，在计算核心中显式加入对应依赖和按键即可。
